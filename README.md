🪑 Jacarandá Mobília - Renewal Landing Page
Official landing page developed for Jacarandá Mobília, currently in production to manage the brand's digital presence transition.

🎨 The Project
The design was crafted to reflect the brand's sophistication and artisanal craftsmanship. It features classic typography using the Crimson Text font and a curated color palette to convey trust and quality.

🛠️ Technologies Used
HTML5 – Semantic structure.

Tailwind CSS – Styling via utility classes and custom theme configuration.

Web Performance – Asset optimization (WebP conversion) to ensure lightning-fast loading speeds.

🪑 Jacarandá Mobília - Landing Page de Renovação

Landing page oficial desenvolvida para a Jacarandá Mobília, atualmente em produção para gerenciar a transição da presença digital da marca.

🎨 O Projeto

O design foi pensado para refletir a sofisticação e o caráter artesanal da marca. Tipografia clássica com a fonte Crimson Text e uma paleta de cores para transmitir confiança e qualidade.

🛠️ Tecnologias Utilizadas

HTML5 - Estrutura semântica.
Tailwind CSS - Estilização via classes utilitárias e configuração de temas personalizados.
Web Performance - Otimização de assets (conversão para WebP) para garantir um carregamento ultrarrápido.
